Instruções

Como usar:

  • Clique esquerdo: Selecionar célula para edição
  • Clique direito: Alternar tipo de célula
  • Tipos de célula:
    • 🔲 Regular - Para respostas
    • Direções básicas:
      • Horizontal (direita)
      • Vertical (baixo)
      • Para cima
      • Para esquerda
    • Curvas 90° (direita/esquerda):
      • Direita-Baixo (→ depois ↓)
      • Direita-Cima (→ depois ↑)
      • Esquerda-Baixo (← depois ↓)
      • Esquerda-Cima (← depois ↑)
    • Curvas 90° (cima/baixo):
      • Baixo-Direita (↓ depois →)
      • Baixo-Esquerda (↓ depois ←)
      • Cima-Direita (↑ depois →)
      • Cima-Esquerda (↑ depois ←)
    • ⧄ Célula Dividida - Duas letras diagonais
  • Edição de dicas: Clique na célula de dica para digitar
  • Células divididas: Clique nos triângulos para digitar letras (suporta ambas direções diagonais)
  • Dicas são colocadas diretamente na grade (estilo Diretas)
  • Não há células bloqueadas - toda a grade é utilizável
